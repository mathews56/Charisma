# Charisma · Skill$ by Mathew$

A 21-lesson charisma and communication course, built as an installable app.
It works offline, keeps your place, reads lessons aloud, and installs on your
phone as **Charisma**.

## Put it on GitHub Pages (free)

You can do all of this from your phone's Chrome browser.

1. **Create a GitHub account** at https://github.com/signup (skip if you have one).
2. **Create a repository:** tap **+** (top right) → **New repository**.
   - Name: `charisma`
   - Visibility: **Public** (free GitHub Pages needs a public repository)
   - Tick **Add a README file**
   - Tap **Create repository**
3. **Upload the app files:** in the repository, tap **Add file** → **Upload files**.
   Select ALL the files from this folder (index.html, manifest.webmanifest, sw.js,
   the three icon PNGs, and this README.md). Upload the files themselves, not the folder.
   Tap **Commit changes**.
   - On a phone, unzip the download first in your Files app (Files by Google: tap the
     zip → Extract), then pick the files from the extracted folder.
4. **Turn on Pages:** go to **Settings** → **Pages** (in the left menu, or under
   "Code and automation").
   - Source: **Deploy from a branch**
   - Branch: **main**, folder **/ (root)** → **Save**
5. **Wait 1–2 minutes**, then refresh the Pages screen. It shows your link:
   `https://YOUR-USERNAME.github.io/charisma/`

## Install it on your phone

- **Android (Chrome):** open your link in Chrome (not inside WhatsApp or Gmail).
  Tap **⋮** → **Install and create shortcut** (or **Install app**) → **Install**.
  **Charisma** appears in your app drawer and on your home screen.
- **iPhone (Safari):** open the link → **Share** → **Add to Home Screen** → **Add**.

Open it once while online so it saves itself for offline use.

## Updating the app later

Upload the new files to the same repository (same names), commit, and wait a
minute. The installed app picks up the new version the next time you open it
with internet.

## Better voices

The app uses your phone's built-in voices. For the best sound on Android:
Settings → search **Text-to-speech** → Preferred engine **Speech Services by
Google** → ⚙ → **Install voice data** → install **English (United Kingdom)** and
**Kiswahili (Kenya)**. Kiswahili words and Kenyan names are then read with the
Kiswahili voice.

## Netlify instead (also free)

On a computer, go to https://app.netlify.com/drop and drag this whole folder
onto the page. Then install from the link it gives you, as above.
